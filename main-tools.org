#+title: Реєстр інструментів

Кожен інструмент реалізовано в окремому самодостатньому org-файлі зі своїм ~run~ (див. [[file:main-tool-outline.org][~outline~]],
[[file:main-tool-texts.org][~texts~]], [[file:main-tool-comments.org][~comments~]]). Оскільки noweb-посилання не резолвяться між org-файлами, спільні для всіх
інструментів частини — оголошення підмодуля, опис для ~tools/list~ і диспетчеризація виклику за назвою —
зведені тут, в одному файлі.

Усі інструменти читають дані з =Figma= лише текстом: скриншоти до реєстру не входять, бо всі дані,
потрібні для аналізу макетів, є в текстових шарах і структурі вузлів.

* Модуль

#+begin_src rust :noweb yes :mkdirp yes :tangle src/tools/mod.rs
  <<Декларації>>

  pub fn list() -> serde_json::Value {
      serde_json::json!([
          <<Tools:Опис>>
      ])
  }

  pub async fn call(http: &reqwest::Client, name: &str, arguments: &serde_json::Value) -> serde_json::Value {
      match name {
          <<Tools:Виклик>>
      }
  }

  <<Визначення>>
#+end_src

* Спільні аргументи

Усі інструменти приймають необов'язкові ~file~ (ключ файлу; без нього береться ~FIGMA_FILE~) і ~refresh~
(пропустити кеш і запитати =Figma= наново). Інструменти для вузлів приймають ще обов'язковий перелік
~ids~.

#+begin_src rust :noweb-ref Визначення
  pub fn file_key(arguments: &serde_json::Value) -> String {
      match arguments["file"].as_str() {
          Some(file) => file.to_string(),
          None => std::env::var("FIGMA_FILE").unwrap(),
      }
  }

  pub fn node_ids(arguments: &serde_json::Value) -> Vec<String> {
      arguments["ids"].as_array().unwrap().iter().map(|id| id.as_str().unwrap().to_string()).collect()
  }

  pub fn refresh(arguments: &serde_json::Value) -> bool {
      arguments["refresh"].as_bool().unwrap_or(false)
  }
#+end_src

* Відповідь інструмента

Успіх і невдача передаються однаково — текстом, а ознака ~isError~ каже клієнтові, що саме це. Причина
невдачі (вичерпаний ліміт, ~403~) так доходить до моделі, а не губиться.

#+begin_src rust :noweb-ref Визначення
  pub fn reply(result: Result<String, String>) -> serde_json::Value {
      match result {
          Ok(text) => serde_json::json!({ "content": [{ "type": "text", "text": text }], "isError": false }),
          Err(text) => serde_json::json!({ "content": [{ "type": "text", "text": text }], "isError": true }),
      }
  }
#+end_src

* Невідомий інструмент

#+begin_src rust :noweb-sep ",\n" :noweb-ref Tools:Виклик
  _ => reply(Err(format!("Невідомий інструмент: {}", name)))
#+end_src
