#+title: Залежності

Компонент проєкту називається ~fm-mcp~ (код проєкту ~fm~ і назва компонента ~mcp~), а крейт —
~figma-mcp~. Сервер не використовує жодного стороннього крейта для самого протоколу =mcp=: =json-rpc=
реалізовано напряму, як у ~org-tmetric-mcp~, див. [[file:main.org][~main.org~]].

* =Cargo=

#+begin_src toml :noweb yes :mkdirp yes :tangle Cargo.toml
  [package]
  name = "figma-mcp"
  version = "0.1.0"
  edition = "2021"

  [dependencies]
  <<Залежності>>
#+end_src

* =dotenvy=

Читає ~.env~ лише під час локальної розробки (~cargo run~); у продуктивному режимі змінні передає сам
=Claude Code= при реєстрації сервера, див. [[file:env.org][~env.org~]]. Крейт ~dotenv~ застарілий, тому використано
~dotenvy~.

#+begin_src toml :noweb-ref Залежності
  dotenvy = "*"
#+end_src

* =serde_json=

#+begin_src toml :noweb-ref Залежності
  serde_json = "*"
#+end_src

* =tokio=

Потрібні можливості асинхронного читання й запису стандартного вводу-виводу (~io-std~, ~io-util~) — саме
через нього сервер спілкується з клієнтом =mcp=.

#+begin_src toml :noweb-ref Залежності
  tokio = { version = "*", features = ["macros", "rt-multi-thread", "io-std", "io-util"] }
#+end_src

* =reqwest=

Залежить від ~tokio~, тому йде після нього.

#+begin_src toml :noweb-ref Залежності
  reqwest = "*"
#+end_src
